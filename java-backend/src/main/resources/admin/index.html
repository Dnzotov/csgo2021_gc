The matchmaker assigns only enabled + Available servers whose category and map fit the search. Classic modes (Casual, Deathmatch, Arms Race, Demolition, Skirmish) just point the player at the server, it stays Available. Only the Accept modes (Competitive, Wingman, Danger Zone) reserve it for the match (Release / Available frees it, otherwise it returns by itself after the reservation TTL). Servers are not health-checked; a server can report itself with POST /api/v1/servers/state.

TEST tool. A fake search is a group of virtual players that fills a Competitive / Wingman / Danger Zone match a real player has started (they never start a match or take a server on their own). The real player searches as usual; when the server of the match is on one of the fake search's maps, the virtual players join it and the match is complete. With no enabled fake search nothing changes. Retail sizes: Competitive 10, Wingman 4, Danger Zone 16, so the real player + fake players have to add up to that (the backend setting backend.required-players.* lowers the number for a test setup that does not use fake searches).
