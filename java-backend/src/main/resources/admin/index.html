The matchmaker assigns only enabled + Available servers whose category and map fit the search. Classic modes (Casual, Deathmatch, Arms Race, Demolition, Skirmish) just point the player at the server, it stays Available. Only the Accept modes (Competitive, Wingman, Danger Zone) reserve it for the match (Release / Available frees it, otherwise it returns by itself after the reservation TTL). Servers are not health-checked; a server can report itself with POST /api/v1/servers/state.

TEST tool. A profile says how many virtual players a Competitive / Wingman / Danger Zone match gets. Real players who search the same mode within the gather window end up in one match (that answers "who is in the match"); then the enabled profile of the mode with the highest priority whose maps (and server) fit the match is applied (that answers "how many fake"): the match gets min(count, capacity - real players) virtual players. The capacity of the mode (Competitive 10, Wingman 4, Danger Zone 16) is never changed and the count is never topped up to it: 3 real + count 2 = a match of 5. Count 0 starts the match with its real players only. Virtual players have no Accept: the match waits for every real player. With the switch OFF, a disabled profile or no profile for the mode, matches wait for real players like without the tool. Changes apply to the next match that is decided.

The fake players tool is switched off on this backend (backend.fake-players.enabled=false).
